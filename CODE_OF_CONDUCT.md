# Code of Conduct

Ferrite follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
v2.1. Be kind, be precise, assume competence.

Enforcement: report to the maintainer through the contact on their GitHub
profile. Maintainers will warn, then temporarily ban, then permanently ban
for repeated or severe violations. No retaliation, ever.
