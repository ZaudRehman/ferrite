    Install

    One download. Done.

    Reproducible: build from source with cargo build --locked and compare. Downloads are unsigned while signing is unfunded, so your OS asks once — what to expect is below.

    WindowsSmartScreen warning → “More info” → “Run anyway” (unsigned build)
    macOSGatekeeper block → right-click the app → Open (unsigned build)
    VerifyMatch the file hash against the SHA256SUMS file on the release page
    StoresHomebrew, winget, Flathub, AUR: manifests ready, listings in progress

    Under the hood

    Boring crypto. On purpose.

    Sync

    Ed25519 TOFU, _ferrite._tcp mDNS under 3s, X25519 6-digit pairing, LWW CRDT, blind relay never sees plaintext.

    Archive

    zstd, FTS5 full-text search, 2GB LRU, pinned items kept eager.

    Privacy

    adblock trie, hourly threat-list updates, k-anonymous lookups over the local proxy, GPC, cookie stripping, De-AMP, canvas/WebGL/audio fingerprint spoofing.

    Vault

    AES-256 (SQLCipher), Argon2id key + BIP39 recovery phrase.

    Builds

    reproducible and checksum-verified; unsigned until signing is funded.

    System requirements.

    Windows 10 1809 and newer (WebView2 Evergreen runtime; the installer link appears on first run if it is absent), macOS 13 and newer, or Linux with X11. Wayland and macOS paths run but are largely unverified.

    Build it yourself.

    Requires Rust 1.96, plus Perl and a C toolchain for encrypted storage. Clone and build locked:

    git clone https://github.com/ZaudRehman/ferrite
cd ferrite
cargo build --locked --release --features ferrite-vault/sqlcipher,ferrite-archive/sqlcipher

    Release builds refuse plaintext storage without the sqlcipher features. Debug builds run unencrypted SQLite for development.

    FAQ

    Plain answers.

    Can I tear tabs into new windows?

    No. Ferrite is single-window; named profiles run as separate processes instead.

    How does sync work without accounts?

    Devices pair by QR code on your network, or anywhere through a relay you host. There is no Ferrite-operated relay.

    Are there extensions?

    No third-party extensions: there is no extension API, so there is nothing for one to abuse. Blocking is built in.

    What data leaves my device?

    Very little: breach checks you run, diagnostics you paste, suggestions you opt into, plus the blocker's upkeep (hourly threat-list refreshes) and per-site signals like GPC that only go out because you loaded the page.
